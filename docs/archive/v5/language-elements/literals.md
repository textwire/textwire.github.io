# Literals

Textwire has the following literal types:

- [String](/v5/language-elements/literals/string) <code v-pre>{{ "Hello, World!" }}</code> or <code v-pre>{{ 'Hello, World!' }}</code>
- [Integer](/v5/language-elements/literals/integer) <code v-pre>{{ 123 }}</code> or <code v-pre>{{ -234 }}</code>
- [Float](/v5/language-elements/literals/float) <code v-pre>{{ 123.456 }}</code>
- [Boolean](/v5/language-elements/literals/boolean) <code v-pre>{{ true }}</code>
- [Nil](/v5/language-elements/literals/nil) <code v-pre>{{ nil }}</code>
- [Array](/v5/language-elements/literals/array) <code v-pre>{{ [1, 2, 3] }}</code>
- [Object](/v5/language-elements/literals/object) <code v-pre>{{ { "name": "John", "age": 25 } }}</code>

String Functions ​

at ​

ts
str.at(index?: integer = 0): string

Returns the character at the given index.

  • When the index is out of bounds, it will return nil type, which will be converted to an empty string when rendered in the template
  • When the index is negative, it will count from the end of the string. For example, -1 will return the last character of the string

Arguments: ​

  1. index (integer) - The index of the character to return. Default is 0, which returns the first character of the string

Input Example: ​

textwire
{{ "Textwire".at(1) }}

Output: ​

html
e

contains ​

ts
str.contains(substr: string): boolean

Returns true if the string contains the given substring, otherwise false. Booleans render as 1 and 0 when printed directly. The function is case-sensitive, so the substring must match the case of the string.

Arguments: ​

  1. substr (string) - The substring to search for

Input Example: ​

textwire
{{ "Hello, World!".contains("World") }}

Output: ​

html
1

Empty Substring

If the substr argument is an empty string, the function will always return true (1 when rendered). It's done this way because an empty string is always a substring of any string

Ignore Case

If you want to search for a substring without considering the case, you can use the lower function to convert both the string and the substring to lowercase:

textwire
{{ "Hello, World!".lower().contains("world") }} {{-- true --}}

decimal ​

ts
str.decimal(separator?: string = ".", decimals?: integer = 2): string

Ensures a numeric value has at least the requested number of decimal places. It pads shorter values with zeroes and leaves values that already have enough decimal places unchanged. It does not round or remove extra decimal places.

  • Integers are padded with zeroes: 123.decimal() returns string "123.00"
  • Numeric strings that already have enough decimal places are returned unchanged: "123.456".decimal() returns string "123.456"
  • Numeric strings with fewer decimal places are padded: "123.4".decimal() returns string "123.40"
  • Strings that are not numbers are returned unchanged

decimals defaults to 2. Negative values are treated as 0.

Arguments: ​

  1. separator (str) (optional) - The separator to use for the decimal. Default is "."
  2. decimals (int) (optional) - How many decimal places to ensure. Default is 2. Negative values are treated as 0

Input Example: ​

textwire
{{ "123".decimal() }}
{{ "123".decimal(".", 0) }}
{{ "123".decimal(".", -1) }}

Output: ​

html
123.00
123
123

format ​

ts
str.format(arg: any...): string

Function format is used to format a string using placeholders. The placeholders are represented by %s in the string, and they will be replaced by the corresponding arguments passed to the function. The number of placeholders in the string should match the number of arguments passed to the function, otherwise, placeholders are just going to be rendered as %s.

Arguments: ​

  1. arg (any) - Any amount of arguments

Input Example: ​

textwire
{{ "I have %s apples, they are %s".format(3, "tasty") }}

Output: ​

html
I have 3 apples, they are tasty

Important Notes ​

  • Too many arguments. If you pass more arguments than the string needs, the rest will be ignored.
  • Not enough arguments. If you pass not enough arguments, the remaining placeholders will be rendered as %s.
  • Required argument. Requires at least 1 argument.
  • Conversion to string. All the arguments passed to the function will be converted to string.

split ​

ts
str.split(separator?: string = " "): array

Function split is used to split a string into an array of substrings. It takes an optional argument separator which is used to split the string. If no separator is provided, it defaults to a space.

Arguments: ​

  1. separator (string) (optional) - What separator to use to split the string. Default is " " (space)

Input Example: ​

textwire
<div>{{ "one two".split(" ") }}</div>

Output: ​

html
<div>one, two</div>
